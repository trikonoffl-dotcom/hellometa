# HelloMeta.ai

Brand assets and product screenshots for HelloMeta.ai, plus the exhibition stall film built from them.

## Stall film

A 48-second, seamlessly looping motion-graphics film for a trade-show screen, in two independently designed cuts:

- `video/out/hellometa-stall-16x9.mp4`: 1920×1080 landscape
- `video/out/hellometa-stall-9x16.mp4`: 1080×1920 portrait

See [`video/README.md`](video/README.md) for the storyboard, the brand and privacy rules applied, the soundtrack, an optional voiceover script, and how to re-render.

## Source assets

- `hellometa-logo.png`, `hellometa-logo-white.png`: the supplied logo, used unmodified.
- `screencapture-*.png`, `Screenshot *.png`: real product UI screenshots.
